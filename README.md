# DayZ Universal Api - 汉化版

本项目是 DayZ Universal Api 的汉化版本，为服务器管理员和模组开发者提供一个稳定、易用的 API 后端。

### 汉化内容
- 所有错误提示和日志消息已翻译成中文
- 所有配置文件和界面已本地化
- 保持了原项目的所有功能，同时添加了中文支持

### 关于翻译功能
翻译功能是项目内置的一个通用翻译服务，支持多种语言之间的互译，包括英语、中文、法语、德语等。它通过 Microsoft Translator API 或 LibreTranslate 实现，提供 RESTful API 接口，方便其他模块调用。翻译功能不是专门针对 DayZ 模组或 Discord 的，而是一个通用的翻译服务，可以被任何需要翻译功能的模块使用。
